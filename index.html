How to send the email HTML via Gmail or Substack

Gmail (paste method): download the file, open it in your browser, select all (Ctrl/Cmd+A), copy (Ctrl/Cmd+C), then paste directly into a Gmail compose window. The inline-styled layout survives the paste.

Substack: create a new post, use More → Import HTML (or paste into the editor as above). Buttons and cards are plain tables with inline styles, so they render in every major email client.

The file is fully self-contained — the only links in it point to the papers themselves.

    Sources & topics

    Tell LitDigest what to follow. Everything is saved automatically in this browser. One honest note up front: ResearchGate and most publisher websites block programmatic access, so LitDigest does not scrape them — it tracks the same journals' papers through the open OpenAlex, Crossref, and arXiv indexes, which is also how the links in your digest are resolved.

    Research topics

    Keywords or phrases, comma- or line-separated. These drive the "Trending on your topics" section (OpenAlex relevance search + Crossref supplement) and the relevance scoring of every paper.

    Tracked journals

    Journals you always want covered. Paste a journal name, ISSN, or URL (journal homepage, Scopus/SJR page, portal.issn.org link, publisher page) — LitDigest resolves it to an exact journal record via the OpenAlex sources API and asks you to confirm before adding.

      Starter list — major journals by field

      One click to add. Names and ISSNs verified against the Crossref/OpenAlex registries (October 2026). Business & management heavy by default — add only what you read.

      Preprint feeds (optional)

      arXiv categories to sweep for new preprints. These land in the "Preprints" section of the digest. Note: arXiv's API does not allow direct browser access (it sends no CORS headers), so LitDigest tries a direct fetch first, then routes the preprint query through a public CORS relay — only the category code is sent, never any keys. If the relays are unavailable the preprint section is skipped and the digest tells you.

      Settings

      Newsletter branding

      Shown as the masthead of the in-app digest, the email HTML, the print view, and the text export.

      AI takeaways (optional, BYO key)

      With an OpenAI-compatible endpoint configured, LitDigest writes a 2–3 sentence plain-language takeaway per paper and a one-line intro per section. Without it, digests use abstract excerpts — everything still works. Your key is stored only in this browser's localStorage and sent only to the endpoint you configure.

      Configuration backup

      Export your topics, journals, arXiv categories, date range, and newsletter title as a .json file, or import one. AI keys are never included in exports.

      LitDigest runs entirely in your browser. Metadata comes from the free, CORS-enabled OpenAlex, Crossref, and arXiv APIs. Coverage depends on index lag — very fresh papers can take days to appear; always follow the DOI link for the authoritative record.
